# RustDo 0.5 plan

One big release (decided 2026-11-28). Built in steps and tested as each part is done; nothing
ships until the whole release is ready and approved. Urgent fixes go out as 0.4.x meanwhile.

## Progress

Done on the 0.5 branch: 1 (Settings pane), 2 (swipes with Undo), 3 and 4 (sections, pinning,
checklists, archive, note ↔ task), 5 (Google Keep import), 6 (Microsoft Sticky Notes import;
the newer Sticky Notes inside OneNote can't be read), 7 (pinned lists: tick, star, add, text
size, completed tasks, keep on top; reorder and opacity not done yet). Next: 8, 12, then the
Android items.

## Look and layout

1. **Settings as a sidebar pane.** ⚙ opens Settings as a full-height panel (not a menu), with
   room for clearer sections (Appearance, Reminders, Sync & sharing, Sticky notes, Backups,
   About). Phones keep it as a full page.
2. **Swipe actions** (phones and tablets).
   - Tasks: swipe right to complete, swipe left to delete.
   - Sticky notes: swipe to archive, into a new Archive section (restore or delete there).
   - An Undo bar after each swipe ("Task deleted · Undo"); Delete key with Undo on desktop.
   - Swipes need a clear sideways movement, so they don't clash with scrolling or ≡ handles.

## Sticky notes

3. **Sections and pinning.** One optional section per note (Shopping, Tech, …), grouped under
   headings on the wall; pinned notes in a row at the top; filter chips once there are two or
   more sections. Invisible until used. No multiple tags, nested sections or section colours.
4. **Checklists inside notes**, plus "turn into a task" and "turn into a note".
5. **Google Keep import** from a Google Takeout zip (no sign-in): notes, colours, checklists,
   pinned, labels (as sections) and archived notes. Re-importing doesn't duplicate.
6. **Microsoft Sticky Notes import** (Windows): read the notes stored on the PC (Sticky Notes'
   local database), no sign-in. Text, colours (mapped), dates; no duplicates. Check the newer
   OneNote-based Sticky Notes storage too.

## Lists everywhere

7. **Pinned lists.** "📌 Pin" on a list:
   - Windows / Linux: a desktop widget window (plain task card in the app's theme, accent
     stripe with the list's icon, name and count; tick, star, add, reorder; always on top,
     opacity, text size, show completed), run by the background helper.
   - Web and Android: a list card on the sticky notes wall.
8. **List sharing in the web app**: move family sharing to the same web-capable connection as
   account sync. The web app needs the Hub on an https:// address.

## Android

9. **Home-screen and lock-screen widget** (lock screen where Android allows it): My Day or a
   chosen list, with tick-off. Needs Java/Kotlin code, so the Android build moves to a
   Gradle setup (see Google Play prep).
10. **Reminders while RustDo is closed.**
11. **Google Play prep** (with the build change above):
    - Android App Bundle (AAB) output in CI, alongside the APK.
    - Target the Android API level Google Play currently requires.
    - Use Android's own photo picker instead of READ_MEDIA_IMAGES (Play restricts that
      permission); drop the in-app photo grid.
    - Draft the data safety answers (no data collected; sync only to the user's own Hub)
      and check the privacy policy (rustdo.app/privacy.html).
    - Closed testing: at least 12 testers opted in for 14 days in a row (new personal
      developer accounts; check the current numbers in the Play Console). Collect testers
      early in a Google Group shared on Discord (about 6 so far).

## Home Assistant

12. **To-do integration**: RustDo lists as Home Assistant to-do lists (dashboards, voice,
    automations), through the RustDo Hub.

## Offered, not decided

- Right-click Cut / Copy / Paste on every text field (now only the sync and sharing fields).
- A test round on the owner's devices (Windows test build, tablet APK, web app) before release.

## Later

- Google Play public release (after closed testing), Flathub and AUR, Microsoft Store listings
  in German, Spanish and French.
